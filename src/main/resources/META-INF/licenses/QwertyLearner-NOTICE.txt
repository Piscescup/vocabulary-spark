Modifications by Vocabulary Spark:
  Converted the source arrays into native Wordbook JSON using QwertyWordbookAdapter.
  Retained only each entry's name; removed translations and phonetic fields.
  Trimmed surrounding whitespace and removed case-insensitive duplicates while
  preserving the first spelling and source order. The postgraduate source has
  3728 entries and produces 3727 unique words.
  Added display names, formatVersion and stable IDs derived from source filenames.

The editable wordbook JSON files are included in the mod JAR and project sources.
These third-party word-list assets retain their upstream licensing notices;
they are excluded from the project's CC0 declaration.

Upstream README credits kajweb/dict for dictionary data and also accepts
community-contributed wordbooks. Original provenance should be considered
separately from the repository's software license.

These are third-party study lists. Their exam labels do not certify complete
coverage of any current official examination syllabus.
